## 📈 How I Built My Basics

I started with very simple programs and gradually moved towards mini projects.

### 1. Understanding the Fundamentals

First, I focused on understanding how basic C programs work:

```c
#include <stdio.h>

int main() {
    printf("Hello, World!");
    return 0;
}
```

From there, I practiced variables, data types, input/output, and operators.

### 2. Practicing Logic

After understanding the syntax, I started solving small problems using:

* Conditions
* Loops
* Mathematical operations
* Logical operators

This helped me understand how to approach a problem and convert it into code.

### 3. Building Small Programs

Instead of only solving individual questions, I started combining different concepts into small programs.

This is where I began creating **mini projects**.

Each project helped me practice multiple concepts together and understand how real programs are structured.

### 4. Learning From Errors

A big part of learning C was debugging.

I made plenty of mistakes while learning — syntax errors, logic errors, incorrect conditions, and problems with loops and functions.

Fixing those errors helped me understand the language better instead of simply memorizing syntax.

## 🔧 How to Run

You can compile the programs using GCC.

```bash
gcc filename.c -o program
```

Then run the program:

### Windows

```bash
program.exe
```

### Linux / macOS

```bash
./program
```
